## 5. Business / permission / data changes

**NO.**
- Only the overlay wrapper changed: `BottomSheet`'s `onClose={() => setIsPaidByOpen(false)}` became
  `ResponsiveModal`'s `onOpenChange={setIsPaidByOpen}` — same boolean-setter semantics, just passed
  directly since `ResponsiveModal.onOpenChange` already receives the next `open` boolean.
- The member-selection handler itself (`form.setValue('paidByMemberId', member.id, { shouldValidate: true, shouldDirty: true })`
  followed by `setIsPaidByOpen(false)`) is untouched.
- No service/repository/Firestore/permission code was touched. `expense-form.tsx`'s validation
  schemas, submit handler, and every other field are unmodified.
- One additive-only UX delta, consistent with every prior `BottomSheet`→`ResponsiveModal` migration
  this rollout: the old sheet had no `showCloseButton` and no keyboard handling (closed only via
  backdrop tap); `ResponsiveModal` adds a close [X] button and Escape-to-close. No existing way to
  close the sheet was removed.

## 7. Targeted P0/P1 verification

No new isolated browser harness was built for this wave. Reasoning:

- This migration is a subset of what Wave 1 already exercised end-to-end: a `ResponsiveModal`
  nested inside the outer form `ResponsiveModal`, opened/closed via state, with a click-driven list
  inside (no sub-form, no validation branch, no nested-nested case) — strictly simpler than
  `AttachmentPicker`'s two-mode picker-with-a-real-form that Wave 1 verified on both desktop
  (Dialog-in-Dialog) and mobile (Drawer-in-Drawer) viewports, including Escape-key isolation between
  the two stacked layers and outer-modal integrity after the inner one closes.
- The only behavioral surface this migration touches — open/close wiring — is exactly what
  `tsc`/build validate at the type level (`onOpenChange: (open: boolean) => void` vs. the old
  `onClose: () => void`), and a manual line-by-line diff confirms the selection handler and its
  `form.setValue` call are byte-identical to before.
- Building a fresh harness to re-prove a composition already proven in the immediately-preceding
  wave would be the "exhaustive matrix for an already-proven wiring pattern" this wave's process
  explicitly says to skip.
